# Workspace

## Overview

pnpm workspace monorepo using TypeScript. Each package manages its own dependencies.

## Stack

- **Monorepo tool**: pnpm workspaces
- **Node.js version**: 24
- **Package manager**: pnpm
- **TypeScript version**: 5.9
- **API framework**: Express 5
- **Database**: PostgreSQL + Drizzle ORM
- **Validation**: Zod (`zod/v4`), `drizzle-zod`
- **API codegen**: Orval (from OpenAPI spec)
- **Build**: esbuild (CJS bundle)

## Artifacts

- **mcq-quiz** (`/`): "Quizzy, Your Own LMS" — full-stack academic quiz platform by Hamid Mukhtar. Features: semester dropdown (1st–8th), Semester 1 subject grid, per-exam drill-down with Midterm/Final/General Quiz slots, always-shuffled quiz engine, custom MCQ count, Easy/Medium/Hard per-question timers, skip/backlog, back button with history stack, cached shuffled options, per-topic result analysis, detailed Q&A report, per-quiz PostgreSQL leaderboards, analytics/comparison sidebar, and Replit OIDC login.
- **api-server** (`/api`): Express 5 REST API. Endpoints: POST /api/quiz-reports (submit score), GET /api/quiz-reports/leaderboard?quizId= (per-quiz leaderboard), GET /api/quiz-reports/analytics?userName= (own analytics), GET /api/quiz-reports/compare?user1=&user2= (side-by-side), GET /api/quiz-reports/users (all usernames), and Replit auth routes. Uses Drizzle ORM + PostgreSQL.

## Key Commands

- `pnpm run typecheck` — full typecheck across all packages
- `pnpm run build` — typecheck + build all packages
- `pnpm --filter @workspace/api-spec run codegen` — regenerate API hooks and Zod schemas from OpenAPI spec
- `pnpm --filter @workspace/db run push` — push DB schema changes (dev only)
- `pnpm --filter @workspace/api-server run dev` — run API server locally
- `pnpm --filter @workspace/mcq-quiz run dev` — run Quizzy frontend locally

## Data

- ICT question data is in `artifacts/mcq-quiz/src/data/questions.ts`
- Entrepreneurship Midterm question data is in `artifacts/mcq-quiz/src/data/entrepreneurship.ts` and currently contains 261 deduplicated MCQs generated from the uploaded DOCX, HTML, and answer-keyed PDF source files
- Curriculum structure and quiz-to-question mapping are in `artifacts/mcq-quiz/src/data/curriculum.ts`
- Quiz reports, per-quiz leaderboards, analytics, and comparison data are stored in PostgreSQL through the API server

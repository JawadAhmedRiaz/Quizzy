2. TIMER SYSTEM

Each question has a per-difficulty timer: Easy = 30s, Medium = 15s, Hard = 10s 
Global quiz timer = sum of all per-question times
Both timers count down simultaneously and are visible
When global timer hits 0 → auto-submit whatever is answered
Per-question timer resets on navigation to a new question but global timer never resets
Display both timers clearly in the quiz UI

3. NAVIGATION RULES
Back Button:

User can go back to view previous questions
Answers on previous questions are LOCKED — cannot be changed
Timer does NOT reset when going back

Skip Button:

Skipped question is removed from current position and appended to the END of the queue
It reappears after all other unanswered questions
Track skip count per question

Break/Pause Button:

Place a "Pause" button in the quiz toolbar, between the Skip and Back buttons
Break options: 5 / 10 / 20 minutes (user selects)
On break: ALL timers pause completely
Show a full-screen modal: "Break Time 🕐" with a visible countdown of break duration
A "Resume Early" button in the modal restores exact quiz state (question, timers, answers) with no resets
When break countdown ends, auto-resume quiz

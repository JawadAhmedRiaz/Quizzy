Quizzy – AI-Powered All-in-One Learning Management System (LMS)

Problem It Solves :
When midterm and final exams approach, university students constantly struggle to find structured practice materials and don't know which topics to focus on. 
Quizzy solves this panic by acting as a complete Learning Management System (LMS). It automatically turns raw study materials (presentations, notes, documents) into tailored practice quizzes, highlights each student's specific weak areas using AI, and keeps students engaged through gamification.

Live URL :
[Click here to use the app](https://quizzy--hamid-mukhtar.replit.app/)

Features :
Admin Dashboard (Full Control) – Manage subjects, push new MCQs, inspect student profiles, and control all course modules from an administrative suite.
AI Content Generator – Upload any course slides, presentations, or documents to automatically generate accurate MCQs published directly to specific subjects.
Interactive Test Engine – Practice mode featuring configurable time limits and instant answer feedback right at the moment of selection.
AI Weakness & Strength Analytics – Comprehensive post-quiz AI feedback dissecting the exact topics you are weak or strong in, ensuring study time isn't wasted on what you already know.
Addictive Gamification Engine – Daily study streaks, milestone badges, and reward systems designed to make exam preparation addictive and consistent.
Student Performance Comparison – Side-by-side student score comparisons, semester breakdowns, and historical performance tracking.
Personalized User Profiles & Replit Auth – Secure user accounts, personalized activity dashboards, and custom user profiles.

AI Feature :
- Powered by Google Gemini 2.5 Flash to parse complex educational documents (PDFs, PPTs) and generate curriculum-aligned multiple-choice questions.
- Generates post-quiz diagnostic feedback highlighting student knowledge gaps and specific study recommendations.
- Example system prompt:
  "You are an expert university academic assistant and curriculum evaluator powered by Gemini 2.5 Flash. Analyze the uploaded course material or quiz results. If generating MCQs, create clear, balanced questions across key course concepts. If evaluating a completed quiz, generate a diagnostic breakdown listing the user's strongest topics, weakest topics, and 3 actionable study recommendations."

Tools, Services, and AI Models
Frontend & Hosting: Replit  
Authentication & Storage: Replit Auth, Replit Database  
Version Control: GitHub (public repository)  
AI Model: Google Gemini 2.5 Flash API  
Frameworks/Libraries: Next.js (App Router), TypeScript, Tailwind CSS, Drizzle ORM
